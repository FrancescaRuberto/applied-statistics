# Applied Statistics

Repository for the **Applied Statistics** module at ATU.

**Author:** Francesca Ruberto
**Academic Year:** 2026/27


## Overview

This repository contains my code, analysis and assessment work for the Applied Statistics module. It uses Python to explore real-world data and to select and perform statistical tests to investigate claims about it.


## Dataset

This project uses the Iris dataset, provided as a CSV file by the Seaborn Data Repository.

The dataset contains 150 observations from three different iris species: Setosa, Versicolor and Virginica.

The dataset can be accessed here:

[ Iris Dataset](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv)
